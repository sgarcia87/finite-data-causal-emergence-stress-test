# Result files

- `final_benchmark_representation_invariance.csv` — exact behavior-preserving refinement experiment.
- `final_benchmark_all_results.csv` — row-level Monte Carlo outputs for all benchmark families.
- `final_benchmark_lowrank_summary.csv` — low-rank recovery summaries.
- `final_benchmark_fullrank_summary.csv` — full-rank control summaries.
- `final_benchmark_publication_endpoints.csv` — compact 100 / 500 / 5,000 samples-per-row endpoints used in the README.

All committed CSVs are generated by `src/final_emergence_stress_benchmark.py`.

## Triadic controls

The `triadic/` directory contains:

- `triadic_partition_recovery_runs.csv` and its CSV/JSON summaries;
- `triadic_hierarchy_population.csv`;
- `triadic_resolved_modes_runs.csv` and summary;
- `triadic_blind_discovery_runs.csv` and its CSV/JSON summary.

They are generated by the three `src/triadic_*.py` programs. The blind
discovery experiment is explicitly exploratory.
