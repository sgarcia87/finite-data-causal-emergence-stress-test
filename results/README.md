# Result files

- `final_benchmark_representation_invariance.csv` — exact behavior-preserving refinement experiment.
- `final_benchmark_all_results.csv` — row-level Monte Carlo outputs for all benchmark families.
- `final_benchmark_lowrank_summary.csv` — low-rank recovery summaries.
- `final_benchmark_fullrank_summary.csv` — full-rank control summaries.
- `final_benchmark_publication_endpoints.csv` — compact 100 / 500 / 5,000 samples-per-row endpoints used in the README.

All committed CSVs are generated by `src/final_emergence_stress_benchmark.py`.

## Triadic controls

The `triadic/` directory contains:

- `triadic_partition_recovery_runs.csv` and its CSV/JSON summaries;
- `triadic_hierarchy_population.csv`;
- `triadic_resolved_modes_runs.csv` and summary;
- `triadic_blind_discovery_runs.csv` and its CSV/JSON summary.
- `triadic_ei_population_partition_controls.csv`;
- `triadic_ei_random_partition_controls.csv`;
- `triadic_ei_finite_null_runs.csv` and summary;
- `triadic_ei_matched_controls_summary.json`.

They are generated by the four `src/triadic_*.py` programs. The blind
discovery experiment is explicitly exploratory.

## Empirical ECM audit

The `empirical_ecm/` directory contains:

- `source_validation.csv` — source hashes and Markov-generator checks;
- `codon_partitions.csv` — the 61 codons and their `B16`, `AA20`, and `L23`
  labels;
- `designated_closure.csv` — closure residuals and 2,000 matched-size controls
  per condition;
- `recovery_runs.csv` — all seeded cardinality-conditioned clustering runs;
- `recovery_summary.csv` and `summary.json` — publication-oriented summaries
  and the predeclared gate decision.

They are generated by `src/empirical_codon_audit.py` from the official ECM
source files under `data/empirical_ecm/`.
